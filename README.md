# 🍑你喜欢 - 黄金蟠桃个人工作台

一个专为黄金蟠桃带货创作者打造的个人工作台 PWA 应用。

## 功能模块

1. **爆款灵感**：全网搜黄金蟠桃爆款视频及脚本文案，支持按平台筛选、搜索、收藏、复制脚本。
2. **二创素材**：每天早上 8 点更新可二次创作的视频素材来源推荐，包含免费商用平台与模板网站。
3. **接单发货**：记录地址、卖出金额、成本金额，自动按天汇总统计利润，支持勾选发货。

## 技术特性

- 侧边栏导航布局，类似 WorkBuddy
- 移动端适配汉堡菜单
- PWA 支持，可添加到手机桌面
- 水蜜桃主题配色
- 数据本地存储于 localStorage
- 支持导出/导入 JSON 数据备份
- 点击头像可上传个人照片

## 使用方式

1. 用浏览器打开 GitHub Pages 地址
2. 点击浏览器菜单「添加到主屏幕」或应用内的「添加到桌面」按钮
3. 开始记录订单、查看灵感和素材

## 数据安全

所有数据均存储在浏览器本地 localStorage 中，建议定期点击右上角 📤 导出备份。
